## Findings and disposition

### F1 — Known finalization blocker: pause during a held draw needs its user decision

- **Evidence:** AD-5, lines 67–71; input conventions, line 131; Deferred, line 196.
- **Assessment:** The state transition and admission-before-pause behavior are fixed. The physical mouse action that invokes it remains an explicit coaching question. It is correctly called out as blocking final status and is not hidden as an implementation choice.
- **Disposition: discuss.** Preserve draft status until the existing clarification is answered, then record that one mapping consistently. This reviewer makes no independent choice.

### F2 — Implementation gates are real dependencies, not independent design permissions

- **Evidence:** AD-12, lines 109–113; shared semantic interface, lines 115–127; Deferred preamble and owner/checkpoint rows, lines 190–207.
- **Assessment:** The spine fixes the feature-level semantic divergences and requires shared publication before dependent work. Bit packing, finite IDs, secondary arithmetic scales, concrete contact/solver bounds, level parameters, and UI bounds are not free choices for separate owners. Those facts do not constitute a new defect at this altitude. The shared schema, numeric parameter set, graphics memory/overlay budget, and physical clock/CDC plan must be completed at their named checkpoints rather than treated as optional follow-up.
- **Disposition: defer to existing gates.** Do not reopen exact simplifier mechanics, solver microarchitecture, or glyph dimensions in this spine unless their prototype changes an adopted external contract.
