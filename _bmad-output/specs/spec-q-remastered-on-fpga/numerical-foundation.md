# Story 3 numerical foundation

This is the implemented isolated arithmetic contract for the user-approved numerical proposal. Public revision 2 records remain unchanged. `rtl/common/` is shared with input/admission; `rtl/physics/` is owned by physics. The controlled motion bank is a development boundary, not the public controller/create/world protocol. Named completion review, contact/admission integration and board evidence remain outstanding.

## Representation and ranges

The adopted `q_numeric_params_draft.vh` remains the format source: signed Q6 geometry (18 bits), Q24 pose (48 bits), Q24 velocity (40 bits), Q24 radians/outer-update angular velocity (32 bits), unsigned 32-bit turn phase, signed Q16 local vertices (32 bits), unsigned Q16 mass (32 bits), unsigned Q16 inertia (64 bits), unsigned Q32 inverses (48 bits) and signed Q16 trig coefficients (18 bits). There is no hidden rescaling of public coordinates. All request payloads are captured immutably; held responses block further requests until retirement.

| Intermediate | Bound and storage |
| --- | --- |
| Q6 endpoint difference | Signed 19 bits; magnitude <=262143. Products retain 38 bits, exact sum is padded to 40. |
| Segment/path length | Floor integer square root U(20,6), at most seven segments summed exactly in U(24,6). Actual generic maximum segment is <370727 raw Q6 units. |
| Weighted center numerator | Endpoint sum in signed Q16 needs 29 bits for generic Q6 inputs; implementation retains 33. Length-weighted product retains 54 bits and signed accumulator 64; seven products fit below 2^57 magnitude. |
| Local coordinate | Original endpoint Q6 converted exactly to Q16 minus rounded stored COM. Generic magnitude <2^28 raw units; signed 32-bit storage has margin. |
| Quadratic/moment | Each local square/cross product retains signed 64 bits; sum retains 67. Segment mass has 25 signed bits (positive). Weighted product retains 92 bits; signed 96-bit accumulation covers the generic sum (magnitude <2^86). |
| Property division | One shared 96-step restoring divider, one final RNE cycle. This covers moments, COM magnitudes, the 2^48 inverse numerator and all denominators. |
| Motion | Gravity uses signed 41-bit widened velocities; norm radicand is 84 bits, with 42-step floor square root and upward rounding. `abs(omega)*extent` retains 65 bits, with upward rescaling to Q24. A shared 64-step floor divider computes movement factors. |
| Transform | Four signed 32x18 products retain 50 bits, rotation sums 51, rounded Q24 rotation 43, world sum 49. Final rounding retains 31 signed Q6 bits before the explicit 18-bit sign-extension check. |

These capacities do not authorize out-of-playfield creation. Admission must enforce its geometry/state policy. Properties reject count outside 2..8, fewer than two distinct samples, computed length below 1024, nonpositive radius or extent above 1024 pixels. Later admission also enforces the common stroke radius and current-world overlap policy. Invalid proposals never insert a body through these helpers.

The shared length is **sum of per-segment floor square roots**, not endpoint displacement or floor of an exact accumulated path length. Duplicate segments contribute zero. The path's quantization underestimate is strictly below 7/64 pixel. Computed equality at 1024 passes. Length counts 0/1 return zero/false without bad-payload; count >8 returns bad-payload without indexing a vertex. Radius is ignored by the length helper.

## Module ports and ownership

Transactional helpers use `clk` and synchronous active-high `rst`, `req_valid/req_ready` and `rsp_valid/rsp_ready`. Each captures one immutable request, deasserts request-ready until response retirement, asserts response-valid independently of ready and holds every response field under stalls. Length uses the exact adopted `length_req_*` / `length_rsp_*` names instead of the short stems. Acceptance is not completion. The caller retains attempt/path/body identity; no helper allocates an ID, inserts a body or debits allowance.

Local-coordinate packing is eight signed 32-bit x samples in bits 0..255 and eight y samples in bits 256..511; sample `i` is at `32*i` in each plane. A transform caller supplies the unchanged local samples from successful properties, or first validates its controlled samples with `q_extent_check` at an extent <=1024 pixels; `q_transform` does not independently repeat that norm scan. `q_ball_properties` is a combinational constant adapter with `is_static` selecting zero inverses; its mass/inertia/inverse outputs have the same suffixes/scales as stroke properties. `q_outer_tick` is a registered one-cycle `tick` enable, not a transactional helper or a new clock.

`q_motion_bank` is the private controlled fixture: `active/outer_tick`, one `load_valid/load_ready` slot with `load_body_count[2:0]` and `load_bodies[Q_BS_TABLE_W-1:0]`; outputs `busy`, one-cycle `commit`, `revision[31:0]`, sticky `fault_flags[Q_FAULT_W-1:0]`, complete `body_count/bodies`, `ball_geometry[Q_BALL_W-1:0]` and `stroke_geometry[Q_STROKES_W-1:0]`. It has no public request/result IDs or world transport. Completion/failure is observed through the fixture's commit/busy/fault levels; the reliable revision-2 wrapper remains future integration work. Consumers should reuse the transactional arithmetic helpers, not adopt this development load interface as a second public protocol.

## Properties and rounding

`q_body_properties` calculates `mass_q16 = length_q6 << 4`; accepted minimum mass is therefore exactly 16384 (0.25). It uses this same length to weight segment midpoints. COM division uses magnitudes and restores the sign after RNE, so negative ties behave symmetrically. Local points preserve the submitted samples exactly at initial phase zero. Properties are usable only when both `rsp_rejected` and `rsp_fault` are false; partially computed fields on rejection/fault are diagnostic values, never insertion permission.

The uniform-wire inertia is accumulated from the retained local samples as `sum(segment_mass * (aa+ab+bb))`; only the final division by `3*2^32` rounds to Q16. One shared signed 32x32 multiply lane serializes the six coordinate products per segment and is reused for extent squares; the weighted moment multiply is separately staged. The positive floor is 4096 (1/16). Inverses are RNE of `2^48 / property_q16`, with explicit zero/unrepresentable-inverse faults. `q_ball_properties` publishes mass 1, solid-disk inertia 72 and their inverses; static geometry explicitly selects zero inverses. Capsule radius belongs to collision extent, not wire inertia.

RNE uses a signed floor quotient and the nonnegative discarded-bit remainder, incrementing above half or at a half with an odd quotient. This is equivalent to symmetric magnitude/sign rounding, including negative ties. Segment length rounds down; norm/extent round up; movement factors round down; phase alone wraps. Every narrowing whose input range is not proved by the above table checks sign extension/range. Saturated or partial results are never treated as valid authoritative updates.

## Rotation provenance and error

`scripts/physics/generate_sine.py` generates the owned 4096x18-bit full-turn ROM using Decimal precision 100, a pinned 80-decimal-place pi, 50 Taylor terms on [0,pi/2], quadrant symmetry and ties-to-even Q16 quantization, with exact axis entries. The first omitted term is below 1e-140 and pi error dominates below 1e-79 before Q16 scaling. No external HDL/table was imported and generation does not depend on platform libm. The table's SHA256 is `a4403745ef38325f06470f0d21f78775c74957b77cc7f798964f3aeba02dfec1`; golden-vector generation checks this hash. Regenerating it is explicit, not part of a normal build. The committed `.mem` file must be included/resolved by the integrating project; `MEM_FILE` may override its run-directory-relative path.

`q_sincos` serializes four synchronous reads through one ROM port: neighboring sine samples and quarter-turn-shifted neighboring cosine samples. It interpolates the low 20 phase bits and rounds the complete coefficient once, including the base sample in the ties-to-even decision. For example, phase 0x00280000 interpolates 201 and 302 to 251.5 and returns 252. `q_transform` uses those same coefficients for every retained local vertex, then publishes one complete packed stroke, with unused points zero. Geometry on a failed transform is zero and `rsp_fault` is asserted; callers retain their previous complete geometry.

The coefficient envelope is <=2^-16 + (2*pi/4096)^2/8 plus 1e-9 Q16 unit table-generation allowance. For extent <=1024 pixels, one pose's vector error is bounded by `2*R*coefficient_error + sqrt(2)/128`, below 0.043 pixel before the small phase/internal-rounding terms. Two endpoint errors plus phase conversion are below the adopted 1/8-pixel reserve. Initial zero-phase reconstruction is exact. The golden generator separately compares its transformed points against real-angle sine/cosine and asserts one-pose error <1/16 pixel for its test fixtures; those sampled checks complement the bound, not replace it.

## Integration and atomic scheduling

`q_integrate` implements one half-update: add the exact Q24 gravity increment 1179648 to vy, use the already impulse-adjusted input velocities, clamp the shared translation/rotation demand, integrate half the resulting velocity with RNE, and add the RNE phase delta `omega * INV_TWO_PI_Q32 / 2^25`. Position, velocity and angular overflow fault; orientation addition intentionally wraps. `req_advance=0` returns the unchanged state without gravity.

The conservative bound is upward-rounded Euclidean velocity norm plus upward-rounded `abs(omega)*R` for a stroke. Both v and omega scale together when it exceeds 27/4 pixels/outer-update. The downward Q24 factor targets 2048 raw Q24 units below that limit to cover subsequent component rounding at R<=1024; the full bound is recomputed, with at most two factor attempts before fault. Circle spin is separately capped at radius*abs(omega)<=8 pixels/outer-update, with a 1024-raw-unit rounding reserve. Extent must include every retained local point plus the shared capsule radius; callers use the exact `q_body_properties` extent, never a smaller estimate.

The per-half-update ledger remains integration <=27/8 pixels, **sum** of all positional-correction translation/rotational-extent motion <=1/2 pixel (Story 4), and transform/quantization reserve 1/8 pixel. Opposite corrections do not cancel that charge. Story 4 must insert contact/impulse/correction work in its reviewed order and abort the staged update if it cannot resolve contacts inside the remaining allowance. No contact solver is implemented by this story.

`q_outer_tick` emits the core-domain rational 60/100000000 enable. Its reset-to-first interval is 1666667 cycles; subsequent intervals are 1666666 or 1666667. Its cadence is independent of active play and no tick is replayed. The controlled `q_motion_bank` accepts an outer enable, uses private six-word staged storage and shares one integrator/transformer across both substeps. A core integration wrapper must connect the rational enable. Load prepares complete geometry before commit; an update publishes every body and geometry together after both substeps. Inactive ticks leave state/revision unchanged. Busy active ticks cancel staged work and set the deadline flag. Numerical failures or revision exhaustion preserve the previous complete state and set their independent sticky fault. Only coordinated synchronous startup reset clears these diagnostics/counter history.

The private `q_body_state.vh` layout is intentionally outside the revision 2 public record headers. Slots are ball 0 and strokes 1..5; local x samples occupy low 256 bits of the local field and y samples the next 256. Controlled loads must come from validated ball/accepted-property state. The bank independently checks the shared ball/stroke radii, extent range and every stroke's declared extent before publication: `q_extent_check` verifies exact `x*x+y*y <= (extent-radius)^2` for all retained local samples with one shared 32x32 square. Under-declared extents fault and retain the old bank. Subsequent updates leave those validated local samples/extents immutable. A larger conservative ball extent tightens its spin limit; it cannot enlarge motion. This module is an arithmetic/snapshot fixture, not an admission, attempt, pause-command or public world transport implementation. Story 7 must wrap public reliable transactions without exporting this development load path as a second protocol.

## Processing and verification evidence

Processing cycles exclude external result stalls. Each instance permits one outstanding request; response stalls do not recompute or mutate the result.

| Work | Bounded schedule / measured xsim maximum |
| --- | --- |
| Square root | ROOT_W fixed iterations after request acceptance; separate setup/retirement in caller. |
| Path length | 25 cycles/segment; 175 measured for seven segments, below target 256. |
| Body properties | `72*(count-1)+41*count+499` cycles for accepted paths; 1331 measured at eight vertices, below target 4096. Includes a private same-source length instance, one shared moment/extent multiply lane and five shared 96-bit divisions. |
| One transform | `6*count+11`; 59 measured at eight points. Five complete eight-point transforms require 295 processing cycles before external arbitration, below target 2048. |
| One half-update | Fixed bounded states and at most two factor attempts; conservative bound 400 cycles, 174 measured across current extreme fixtures. |

Reserve 6000 cycles for this fixture; this excludes every Story 4/5 contact/admission operation. |
